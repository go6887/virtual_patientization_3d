# Vscan Air CL用・位置追跡マーカーアタッチメント

大きい曲面のプローブ側を使う前提で、背面のくびれに取り付ける試作品です。
曲面に沿うサドル、短い補強支柱、5面マーカー台を一体化しています。
前回作成した写真由来の外観モデルに合わせた設計で、実機への装着は未確認です。

## 最初に使うファイル

| ファイル | 用途 |
|---|---|
| `Vscan_saddle_fit_test.obj` / `.stl` | 先に印刷する、装着確認用のサドルだけの試験片 |
| `Vscan_marker_attachment.obj` / `.stl` | マーカー台を含む一体型の本体 |
| `Vscan_marker_attachment_assembly.blend` | プローブ・ベルト・パッド・貼付位置を確認する組立モデル |
| `marker_labels_32mm.pdf` | この台に合うマーカー貼付紙。A4・100%で印刷 |
| `marker_geometry_42mm.json` | マーカーの寸法、面、向き、四隅の3D座標 |

OBJ/STLは1単位=1 mm。印刷部品だけの、閉じた単一メッシュです。MTLは不要です。
Blenderの組立モデルには印刷しない参考プローブ、ベルト、パッド、紙も含みます。

## 準備するもの

- 3Dプリントした本体1個。まずサドル試験片で装着確認。
- 幅10 mm、長さ約200 mmの、伸びにくい面ファスナーバンド2本。
  両端を穴で折り返して固定できる薄いタイプを使用します。必要な長さは実物で調整。
- 10 × 12 mm、厚さ1 mmのシリコンパッド4枚と薄い接着層。
  緩い箇所には0.5 mm刻みで薄いシムを追加します。
- マーカーを貼るための薄い接着材。紙を平らに保ちます。

## 取り付け

1. 大きい曲面レンズを上に、Vscanの文字がある面を正面にして、組立画像と同じ向きに置きます。
2. サドルの内側にパッドを4枚貼ります。左右2か所×上下2か所で、帯を通す穴から離します。
   初期厚さは1 mm。厚いスポンジではなく薄いパッドで隙間を調整します。
3. プローブの背面側にサドルを当てます。上縁は中央の白いくびれ、下縁は電源ボタンより上です。
   内面は参考モデルより約1.6 mm離してあります。実物の形に合わせ、パッドを局所的に調整します。
4. 上下それぞれのバンドを、左右の穴を端部アンカーとしてプローブ前面側に回します。
   バンド両端を各穴に1枚の厚みで通し、サドル前縁の肉部分に回して、前面側のバンド自身へ折り返して留めます。
   折り返した二重部分は穴の外に置きます。穴は約11.4 × 3.2 mmです。
   支柱のあるサドル背面を横切る戻り経路は使いません。
5. レンズ、電源ボタン、表示ランプを避けたまま固定します。
   キューブを軽く押し、プローブとの相対的なずれや揺れを確認します。実機の握り方も確認してください。
6. サドル試験片の装着が良ければ、本体を印刷して同じパッド構成・位置で取り付けます。

パッドや締め付けでは収まらない形状差がある場合は、実測して内面を修正してください。
力ではめ込むスナップ式にはしていません。充電・清掃時には外せる構成です。

## 印刷の開始条件

機種・材料に合わせて調整するための初期案です。

- 材料：PETGを想定。試験片はPLAでも形状確認が可能。
- ノズル0.4 mm、積層0.2 mm、外周4本、上下6層、インフィル15〜20%を目安に設定。
- サポートを有効にします。サドル下面には造形物上から始まるサポートも必要です。
- OBJ/STLは、キューブのID0面をベッド側に向けてあります。本体外寸は約54.3 × 42 × 70 mm。
- 角やベルト穴、パッドが当たる面のサポート痕を仕上げます。マーカーを貼る平面を曲げないでください。

キューブは外形を閉じたCAD形状です。スライサーのインフィル設定で内部を軽くします。
100%充填を前提とした設計ではありません。実際の重量・造形時間はスライサーで確認してください。

## マーカーの貼り方と追跡設定

台の外寸は42 mm角、黒枠は32 mm角、貼付紙は40 mm角です。
同梱PDFをA4・100%で印刷し、100 mm確認スケールと黒枠32 mmを実測してください。
元の50 mmキューブ／黒枠40 mm用の設定は、そのままでは一致しません。

| ID | 組立時の面 | 紙の上方向 |
|---|---|---|
| 0 | プローブから最も離れた背面側 | 大きい曲面レンズ側 |
| 1 | プローブ正面から見て左側 | プローブから離れる方向 |
| 2 | 大きい曲面レンズ側 | プローブから離れる方向 |
| 3 | プローブ正面から見て右側 | プローブから離れる方向 |
| 4 | 小さい平面レンズ側 | プローブから離れる方向 |

各紙を面の中央、各辺から1 mm内側に貼ります。支柱が付く面には貼りません。
組立モデルの黒白模様は貼付位置を示す参考表示で、印刷用OBJ/STLには入っていません。

`marker_geometry_42mm.json`は説明用の幾何データです。既存の`marker_model.json`と同じ形式とは限りません。
使用する追跡ソフトに、黒枠寸法・各面の位置・向き・角の順序を反映してください。
JSON内のプローブとの位置関係はCAD上の推定値で、実機での校正結果ではありません。
紙・接着層の厚み、実際の固定位置、プローブ基準点や超音波画像面との対応は実機で校正してください。
再装着やパッド構成変更時も、この対応を確認します。

## 今回確認した範囲

- 本体・試験片とも、単一の閉じたメッシュ。OBJ/STLの面・接続・再読み込みを検証済み。
- 参考プローブの全部品との幾何学的な交差なし。
- 5面のマーカー四隅は所定の平面上。PDFのIDは元資料と一致。
- 組立レンダーから、見えているID0・1・2およびID3をOpenCVで検出。

実物のはまり方、保持力、印刷強度、カメラ実写での追跡精度は未検証です。
まず机上で試験片の装着と固定を確認するための初回試作として使用してください。
